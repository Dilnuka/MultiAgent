# 🚀 Quick Start Guide - Enhanced AI Risk Assessment System

## ⚡ Get Started in 30 Seconds

```bash

python run_enhanced_ui.py
```

Open your browser to: **http://localhost:8501**

- Color-coded results with professional styling

## 🆘 Troubleshooting

### "Risk analysis failed"
- Check LM Studio is running on `http://127.0.0.1:1234`
- Verify your `.env` file has correct API settings

### "Payment failed"
- Use exact demo card: `4242 4242 4242 4242`
- Expiry: `12/25`, CVV: `123`
- Enter any name

### "Page not loading"
- Check port 8501 is available
- Try refreshing browser
- Run `streamlit run src/ai_latest_development/enhanced_ui_app.py` directly
